Open a new terminal and run `ocx --remote --global add uv:0.10` to install your first package.

The commands are thin per-shell installers served by [setup.ocx.sh](https://setup.ocx.sh/). See [Installation](/docs/installation) for pinned versions, manual downloads and the other install options.

## Install in CI

In GitHub Actions, add the [`ocx-sh/setup-ocx`](https://github.com/ocx-sh/setup-ocx) step. It installs ocx, and in a project with an `ocx.lock` it pulls the pinned toolchain and exports its environment. Pin the action to a commit SHA:

```yaml
- uses: ocx-sh/setup-ocx@25fa771f8572572dc64528db89560de68a163a0e # v1.4.0
```
