### A heading with Sigstore in it

The first usage links: Sigstore. The second usage on the page stays text: Sigstore.

Inline code stays as written: `Sigstore`, and so does a [link to Sigstore](https://www.sigstore.dev/) and the name `multi-semver`, `semver.json` and --semver.

```sh
cosign verify --certificate-identity Sigstore
```
