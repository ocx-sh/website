ocx dependencies are pinned by <Tooltip term="OCI digest">A SHA-256 content fingerprint. The exact bytes of the dependency determine the digest — the same bytes always produce the same fingerprint. No index lookup, no version resolution, no "find me the latest compatible build."</Tooltip>, not by version ranges.
