---
title: Toggle button
description: A button that switches one option on or off and keeps its pressed state, with no client framework.
---

import PropsTable from '../../../components/showcase/PropsTable.astro';
import Stories from '../../../components/showcase/Stories.astro';

Use it for one independent on/off choice, such as pinning a version or showing hidden files. For a
choice among two to five options, use a [toggle group](../toggle-group/). It is a native `<button>`
with `aria-pressed`, so the pressed state is in the page before any script runs.

## Events

| Event                      | Detail               | When                                                           |
| -------------------------- | -------------------- | -------------------------------------------------------------- |
| `ocx:toggle-button:change` | `{ pressed, value }` | The button is pressed or released. It bubbles from the button. |

## Keyboard

- <kbd>Tab</kbd> moves focus to the button.
- <kbd>Space</kbd> <kbd>Enter</kbd> toggle it.
