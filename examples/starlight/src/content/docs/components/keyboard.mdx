`Kbd` renders one or more keys, joined by `+`, as `<kbd>` elements. `Mod` is the one adaptive
key — Cmd on macOS, Ctrl on Windows and Linux — so a shortcut written once works everywhere. A
handful of other keys are always literal but still render a per-OS glyph (Alt shows as Option on
macOS; Super shows as the Windows key). Every variant renders on the server; a tiny script in the
document head picks which one shows, so nothing waits on the client and nothing flickers.
