A native `<input>` with its `<label>`. The `start` and `end` slots hold an icon, a text addon or a ghost button inside the same box ([InputGroup](../input-group/)). Focus a field to see its border turn the focus colour. A `type="number"` field gets a stepper; the arrow keys keep stepping it too.
Switch the theme in the header to check dark mode.
