A text column and a visual, side by side on wide screens and stacked on narrow ones. Each section
fades in once as it scrolls into view; with reduced motion it is shown at once.

With `flip` the visual moves to the left on wide screens; sections alternate. The visual slot takes
an image or a code block. The canvases are 720px wide, so they show the stacked layout; open a story
in a new tab for the two-column one.
