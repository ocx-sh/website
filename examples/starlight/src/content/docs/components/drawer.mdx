A sheet that slides in from an edge. It behaves like a modal dialog, and a swipe back towards its
edge closes it.

Slots: `trigger` (the trigger button's content; no trigger when absent) and the default slot (the body).

## Events

- `ocx:drawer:change` `{ open }`: the drawer opens or closes.

## Keyboard

| Key | Action |
|---|---|
| Enter, Space | On the trigger: open the drawer; focus moves into it. |
| Tab, Shift+Tab | Move focus within the drawer; it wraps at the ends. |
| Escape | Close the drawer; focus returns to the trigger. |
