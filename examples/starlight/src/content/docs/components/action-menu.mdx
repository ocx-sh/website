A menu of commands (APG menu pattern). Choosing an item fires `ocx:menu:select`. Navigation
links belong in [Menu](../menu/), not here.

An item takes a leading `icon` from the [icon registry](../iconography/catalog/); once one item
has an icon, the others keep an empty slot so the labels stay aligned.

## Events

- `ocx:menu:select` `{ value }`: an item is chosen by click, Enter or Space.
- `ocx:menu:change` `{ open }`: the menu opens or closes.

## Keyboard

| Key | Action |
|---|---|
| Enter, Space, ArrowDown | On the trigger: open the menu and highlight the first item. |
| ArrowUp | On the trigger: open the menu. In the menu: previous item. |
| ArrowDown | Next item. |
| Home, End | First or last item. |
| A letter | Highlight the next item starting with it. |
| Enter, Space | Choose the highlighted item and close. |
| Escape | Close; focus returns to the trigger. |
