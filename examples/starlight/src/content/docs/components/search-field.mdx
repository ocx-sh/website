Use it to filter a list or table, or to search a set of pages. For a free-form value that is not a
search, use an [Input](../input/). The clear button is a real button and it shows only while the
field holds text. Without JavaScript the browser's own clear behaviour applies and the button stays
hidden.

## Events

| Event                    | Detail | When                                                                                                    |
| ------------------------ | ------ | ------------------------------------------------------------------------------------------------------- |
| `input`                  | none   | The native event. It also fires when the clear button or Escape empties the field, so listeners see it. |
| `ocx:search-field:clear` | none   | The clear button or Escape emptied the field. It bubbles from the input.                                |

## Keyboard

- <kbd>Tab</kbd> moves from the input to the clear button.
- <kbd>Enter</kbd> submits the surrounding form, or fires the native `search` event.
- <kbd>Esc</kbd> clears a field that holds text and keeps focus in it. A surrounding dialog stays open. On an empty
  field it does nothing, so the dialog closes as usual.
