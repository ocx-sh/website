final; the machine loads on the first hover or focus.

Each item's default slot is its section. Headings render as `<h3>`.

## Events

- `ocx:accordion:change` with detail `{ value }`, when a section opens or closes; `value` lists the open ones.

## Keyboard

- <kbd>Enter</kbd> or <kbd>Space</kbd> opens the focused section, or closes it when allowed.
- <kbd>↓</kbd> and <kbd>↑</kbd> focus the next or previous heading, wrapping at the ends.
- <kbd>Home</kbd> and <kbd>End</kbd> focus the first or last heading.
