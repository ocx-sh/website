| Event | Detail | When |
| --- | --- | --- |
| `ocx:tabs:change` | `{ value }`, the slug of the selected label | A group selects another tab, or follows a synced one. |

## Keyboard

APG tabs with automatic activation: the tab list is one Tab stop.

- <kbd>←</kbd> <kbd>→</kbd> select the previous or next tab, wrapping at the ends.
- <kbd>Home</kbd> <kbd>End</kbd> select the first or last tab.
- <kbd>Tab</kbd> moves into the selected panel.
