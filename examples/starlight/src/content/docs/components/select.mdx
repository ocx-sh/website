A button that opens a listbox of options, on the Zag select (loaded on first hover or focus). A
hidden native `<select>` carries the value into forms; options appended to it at runtime join the
list. The `start` and `end` slots put a control inside the box, such as a sort-direction toggle.

## Events

- `ocx:select:change` `{ value }`: An option is chosen.

## Keyboard

- <kbd>Enter</kbd> <kbd>Space</kbd> <kbd>↓</kbd>: Opens the list on the chosen option.
- <kbd>↓</kbd> <kbd>↑</kbd> <kbd>Home</kbd> <kbd>End</kbd>: Moves the highlight.
- <kbd>Enter</kbd>: Chooses the highlighted option and closes.
- <kbd>Esc</kbd>: Closes without a change.
- Letters: Typeahead: highlights the next option starting with them.
- <kbd>Tab</kbd>: A control in the `start` or `end` slot is its own tab stop.
