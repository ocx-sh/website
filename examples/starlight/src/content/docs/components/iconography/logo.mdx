`<Logo>` inlines the theme's `logo.svg` byte for byte, so the mark paints with the page and its
box is reserved by `width` and `height` before any CSS loads. Colour comes from CSS only: the
accent, or the text colour with `tone="current"`. The wordmark is text in the mono font, never
artwork. The header's brand link renders through it.
