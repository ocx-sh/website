Every icon in the theme comes from one registry, generated from Lucide, Simple Icons and a few
custom glyphs, and renders through `<Icon>`: inline SVG in the
text colour, painted with the page, never loaded later. The [Iconography](../) page
says when to use which icon; the [catalog](../catalog/) lists them all with a search.
