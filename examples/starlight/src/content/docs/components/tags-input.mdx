A text field that collects values as removable [tag](../tag/) chips, on the Zag tags-input with a combobox for
the suggestions (loaded on first hover or focus). Typing filters the suggestions (fuzzy by default; values already
added are left out) and <kbd>Enter</kbd> adds the highlighted one. Text that names a suggestion by value or label
adds it; other text becomes a tag only with `allowCreate`, on by default without suggestions.

## Events

| Event                    | Detail                                                 | When                                                                              |
| ------------------------ | ------------------------------------------------------ | --------------------------------------------------------------------------------- |
| `ocx:tags-input:change`  | `{ value }`, the tags in order                         | A tag is added or removed.                                                        |
| `ocx:tags-input:create`  | `{ value }`                                            | An added tag is not one of the suggestions.                                       |
| `ocx:tags-input:invalid` | `{ value, reason: 'unknown' \| 'duplicate' \| 'max' }` | Text is rejected: outside the list, already added, or past `max`. The text stays. |

All bubble.

## Keyboard

- Typing: filters the suggestions and opens the list.
- <kbd>↓</kbd> <kbd>↑</kbd>: open the list, move the highlight.
- <kbd>Enter</kbd>: adds the highlighted suggestion, else the typed text when it names a suggestion, else creates it
  when allowed.
- <kbd>,</kbd> (the delimiter) and paste: add the typed text by the same rule; a paste is split on the delimiter.
- <kbd>Backspace</kbd> on an empty input: highlights the last chip; again, removes it.
- <kbd>←</kbd> <kbd>→</kbd> from the start of the input: move between the chips.
- <kbd>Delete</kbd> <kbd>Backspace</kbd> on a highlighted chip: remove it.
- <kbd>Esc</kbd>: closes the list; again, clears the text.
- Leaving the field clears unadded text.
