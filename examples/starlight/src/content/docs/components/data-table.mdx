A `DataTable` takes rows from the page and adds sorting by column, a text filter and pages. The
server renders its rows in their final order, so the first paint is the final one; the sort and
filter code loads on the first hover, focus or touch. For a static table, write Markdown:
[Tables](../tables/).

## Events

The table fires none of its own; its pagination's event bubbles out of it.

| Event | Detail | When |
| --- | --- | --- |
| `ocx:pagination:change` | `{ page: number }` | The page changes, by the pager or by a sort or filter (back to page 1). |

## Keyboard

A native table with buttons in the sortable headers (`aria-sort` on the sorted one), a search field
and the pagination landmark.

- <kbd>Tab</kbd>: Filter field, then each sort button, the scroll region, then the page controls.
- <kbd>Enter</kbd> / <kbd>Space</kbd> on a header: Sort by it ascending; again, descending.
- Typing in the filter: Rows narrow as you type; the row count below the table is announced.
- <kbd>Escape</kbd> in the filter, or its clear button: Empties it and shows every row.
