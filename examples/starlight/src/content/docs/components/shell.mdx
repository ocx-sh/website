`Shell` (`@ocx-sh/theme/layouts/Shell.astro`) is the whole HTML document for a plain Astro site: the
pre-paint theme script, `tokens.css`, `base.css`, the self-hosted fonts, the header, a `main` landmark and the
footer. Without `brand` it renders the ocx.sh chrome (sections, ecosystem menu, install, GitHub, theme toggle) and
the `nav.json` footer; with `brand` it renders a neutral header with the page's own links. `nav` or `footer`
without `brand` throws. On a narrow viewport the menu button opens a native popover list, with no JavaScript.

The Starlight overrides render the same `SiteHeader` and `SiteFooter`; `Shell` is the way to use them directly.
Shell does no claim, `site` or `trailingSlash` validation: that stays in the Starlight plugin and `ocx-site check`.
Live pages: [ocx mode](/docs/shell/), [neutral mode](/docs/shell/neutral/), [with a sidebar](/docs/shell/sidebar/), [`width="wide"`](/docs/shell/wide/)
(a nested nav, an external link), [`width="full"`](/docs/shell/full/), [a home link with `match: 'prefix'`](/docs/shell/prefix/)
and [ocx chrome with its own header link, footer link and icon](/docs/shell/extras/).

The body is a sticky-footer frame: the footer sits at the viewport bottom on a short page. `width` sizes the
column: `prose` (default), `wide` (`--ocx-page-max`, for a card grid or a docs page with sidebar, prose and
outline) or `full` (no cap, no gutter). A neutral nav marks one link current, the longest href prefix of the
path; an absolute `http(s)` nav or footer link opens in a new tab with the external icon; a header with no
`nav` has no menu button. The theme script sets `data-theme` and `<html class="dark">`, moves a 0.5.x
visitor's `vitepress-theme-appearance` choice once into `starlight-theme`, and follows the OS until the visitor pins a scheme.

## Props

`Shell` props (`slots`: `head`, the default slot, `header-search`):

| Prop | Type | Description |
| --- | --- | --- |
| `title` | `string` | Required. The document title. |
| `description` | `string` | The meta description. |
| `canonical` | `string \| URL` | Default: the request path on `Astro.site`, when a site is set. |
| `activeSection` | `string` | ocx mode only. Default: the section the request path belongs to. |
| `brand` | `{ title; wordmark?; logoSrc? }` | Given means neutral mode. |
| `nav` | `{ label; href; title?; match? }[]` | Neutral mode header links. `match: 'prefix'` on a home link (`/` or the base) keeps it current under that prefix unless a longer link matches. |
| `footer` | `{ links: { label; href; title? }[]; note? }` | Neutral mode footer. |
| `extraNav` | `{ label; href; title? }[]` | ocx mode: the page's own header links, after the `nav.json` sections. The longest matching one is current and then no section is. |
| `extraFooterLinks` | `{ label; href; title? }[]` | ocx mode: footer links appended after the `nav.json` ones. `title` is a tooltip. |
| `icon` | `string` | The page's own icon href: replaces the default `favicon.svg` (ocx mode) or the empty icon (neutral mode). |
| `skipTarget` | `string` | The element id the skip link lands on. Default `main`; a docs page passes the id of its prose column to skip the sidebar too. |
| `width` | `'prose' \| 'wide' \| 'full'` | The content column and the footer under it. Default `prose`. |

## Events

| Event | Detail | When |
| --- | --- | --- |
| `ocx:cycle-button:change` | `{ value, previous }` | The theme toggle advances; the page flips `data-theme` and `html.dark`, and stores `starlight-theme`: the scheme, or `auto` when it equals the OS scheme. |
| `ocx:toast` | `{ title, ... }` | Any script dispatches it on the document; the footer's toaster shows the toast. |

## Keyboard

The section nav is a Zag navigation menu in ocx mode.

- <kbd>Tab</kbd> moves through the links, the ecosystem trigger, the install link and the tools.
- <kbd>Enter</kbd> or <kbd>Space</kbd> on the ecosystem trigger opens its menu; <kbd>Esc</kbd> closes it.
- The mobile menu is a native popover: <kbd>Enter</kbd> opens it, <kbd>Esc</kbd> closes it.
