Native radios sharing one `name`: arrow keys and form submit are the browser's, before any script
runs. The Zag machine loads on first hover or focus and reports the checked value.

## Events

- `ocx:radio-group:change` `{ value }`: Another radio is checked.

## Keyboard

- <kbd>Tab</kbd>: Moves focus to the checked radio (else the first).
- <kbd>↓</kbd> <kbd>→</kbd> / <kbd>↑</kbd> <kbd>←</kbd>: Checks the next / previous radio, skipping disabled ones.
- <kbd>Space</kbd>: Checks the focused radio.
