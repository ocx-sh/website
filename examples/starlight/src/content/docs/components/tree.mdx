Everything ocx stores lives under a single root. A tree is `selectable` when a click selects a row
(a directory also collapses); click it again, press <kbd>Escape</kbd>, or click outside the tree to
clear the selection.

## Props

A tree is a `<Tree>` of nested `<Node>`s (`TreeNode.astro`); a `<Description slot="description">`
(`TreeDescription.astro`) fills a node's description column. A node is a directory when its default
slot holds child nodes.
