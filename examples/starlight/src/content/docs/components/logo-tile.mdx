A tile for cards, table rows and detail headers. The monogram (up to two initials on one
of four hues picked by hashing the name) paints with the markup. The logo is a lazy image stacked
over it: it cross-fades in once it has loaded and shows bare, with no box, background or radius. A
logo that fails (also one that failed before the script ran) leaves the monogram; a failed logo
is retried once with the `fallback` URL first, when you pass one. With neither a logo nor initials the tile shows a cube.
The box size is a token, so images blocked never move layout; the cross-fade stands still under
`prefers-reduced-motion: reduce`. The tile is decorative, so put the name beside it.

The four hues are the `--ocx-color-monogram-0` to `-3` tokens, each with a `-tint`, in both schemes:
override them to rebrand every tile. To fill a tile from script (a card cloned from a template),
render one with no `name` and no `src` and call `fillLogoTile(tile, { name, seed, src, fallback })` from
`@ocx-sh/theme/logo-tile`; `monogramInitials` and `monogramHue` are exported from there too.

## Script API

`@ocx-sh/theme/logo-tile` exports `fillLogoTile(tile, { name, seed?, src?, fallback? })`,
`monogramInitials(name)`, `monogramHue(seed)` and `install()` (settles logos that finished loading
before the script ran; the tile's page script calls it).
