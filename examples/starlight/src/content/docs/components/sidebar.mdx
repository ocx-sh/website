The sidebar for a site that is not Starlight: grouped links in a labelled `nav`, rendered at build time. A
Starlight site keeps its own sidebar (the plugin overrides it); this one wears the same look, so a plain
Astro section of ocx.sh reads like the rest. The page marks its own current item. Nothing loads for it: no
script, no request. A [live page](/docs/shell/sidebar/) puts it beside `main` on `Shell`.
