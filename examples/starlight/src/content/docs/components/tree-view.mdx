An interactive tree for app-like hierarchies (a package picker, a file browser); the machine loads
on first hover or focus. Icons, descriptions and `selectable` work as in the native
[Tree](../tree/), which suits documentation listings.

| Event | Detail | When |
| --- | --- | --- |
| `ocx:tree-view:select` | `{ value: string[] }` | The selection changes. |
| `ocx:tree-view:expand` | `{ value: string[] }` | A branch opens or closes. |

## Keyboard

APG [tree view](https://www.w3.org/WAI/ARIA/apg/patterns/treeview/) pattern.

- <kbd>↓</kbd> / <kbd>↑</kbd>: Next / previous visible node.
- <kbd>→</kbd>: Open a closed branch; on an open one, go to its first child.
- <kbd>←</kbd>: Close an open branch; otherwise move to the parent.
- <kbd>Home</kbd> / <kbd>End</kbd>: First / last visible node.
- <kbd>Enter</kbd> / <kbd>Space</kbd>: Select a selectable node (a branch also toggles).
- <kbd>Escape</kbd>: Clear the selection.
- <kbd>*</kbd>: Open every sibling branch.
- letters: Move to the next node starting with them.
