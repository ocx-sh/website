The [Input](../input/) box with slots. Put a control with the class `ocx-ui-input-group__input`
in the default slot; focus, danger and disabled are drawn from that control's own state. For the
common case, give `Input` a `start` or `end` slot instead. It ships no JavaScript. A bare `type="number"` control shows no spin buttons (arrow keys still step it); for the Decrease / Increase stepper use `Input`.
