A native `<button>`, or an `<a>` when `href` is set, restyled on `--ocx-*` tokens. Tab to a button to
see its 2px focus ring, and hover it for the hover state. Icons go in the slot as
[`<Icon>`](../iconography/icon/), never as a text arrow or an emoji. Switch the theme in the header to check
dark mode.
