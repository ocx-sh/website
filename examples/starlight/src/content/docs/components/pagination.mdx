A window of numbered pages with ellipses. Without `href` the pages are buttons and a change fires
`ocx:pagination:change`; with an `href` template they are links, and work without JavaScript.

## Events

| Event | Detail | When |
| --- | --- | --- |
| `ocx:pagination:change` | `{ page: number }` | The current page changes (links mode: before the navigation). |
| `ocx:pagination:set` (listened) | `{ count: number }` | Dispatch it on the root to change the item count of a live pagination. |

## Keyboard

Links or buttons in a `nav` landmark; no APG widget pattern applies.

- <kbd>Tab</kbd>: Next page control; a disabled prev/next is skipped.
- <kbd>Enter</kbd>: Go to that page (buttons: <kbd>Space</kbd> too).
