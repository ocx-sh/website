A Markdown table stays static: no sorting or filtering, the head in mono caps, long code and URLs
break anywhere. It fills the column and scrolls sideways when its words cannot fit. For sorting, a
filter and pages, use the [DataTable](../data-table/).

## Markdown tables

| Command | What it does |
|---|---|
| `ocx add` | Add a package binding to `ocx.toml` |
| `ocx lock` | Resolve tags to digests and write `ocx.lock` |
| `ocx exec` | Run a command with the toolchain on `PATH` |
