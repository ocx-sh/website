A palette for searching a site or a catalog. The header trigger, <kbd>Ctrl</kbd>+<kbd>K</kbd> (<kbd>⌘</kbd>+<kbd>K</kbd>)
and <kbd>/</kbd> open a modal "Search" dialog, the [dialog](../dialog/)'s Zag machine, `--ocx-palette-top` from the top at
`--ocx-palette-width`, with the search bar pinned and only the results scrolling. Its input is a combobox: the arrow keys
move a highlight while focus stays in the field. Rows are real links, and picking one closes the palette before the page
navigates.

`ui/CommandPalette.astro` renders the shell; your own module supplies the data through `mountCommandPalette`:

```astro
<CommandPalette triggerLabel="Search packages" hint="Search packages by name or keyword." />

<script>
  import { mountCommandPalette } from '@ocx-sh/theme/command-palette';

  const root = document.querySelector<HTMLElement>('.ocx-cmdpalette')!;
  mountCommandPalette(root, { source: () => import('./search.js') });
</script>
```

Nothing heavy loads before input: the dialog machine and your `source` module load on the first open. The module
exports `search(query, signal)`, returning groups of rows, and optionally `warm()` (runs on every open):

```js
export async function search(query, signal) {
  const items = await findPackages(query, { signal }); // [{ href, label, description }]
  return [{ label: 'Packages', items }];
}
```

Rows are drawn with `textContent`; one whose `href` is not http(s) or relative is dropped. `search` should cap its
results; every row is drawn. A failed `source` import or `search`
shows the `error` line; the next query retries. A newer query aborts the older one's `signal` and its answer is ignored.

`mountCommandPalette(root, options)` returns `{ destroy() }`.

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `source` | `() => Promise<{ search, warm? }>` | required | Dynamic `import()` of the search module. |
| `slash` | `boolean \| () => boolean` | `true` | Open on <kbd>/</kbd>; `false`, or a function answering false, leaves it to the page. |

## Events

| Event | Detail | When |
| --- | --- | --- |
| `ocx:dialog:change` | `{ open }` | The palette opens or closes. |

## Keyboard

| Key | Action |
| --- | --- |
| Ctrl+K, ⌘K | Open; with it open, close. Ignored while typing in another field. |
| / | Open, unless the page opted out or you are typing in a field. |
| ArrowDown, ArrowUp | Move the highlight, wrapping at both ends. The first row starts highlighted. |
| Enter | Open the highlighted row (Ctrl/Cmd+Enter: new tab). |
| Escape | Close in one press, whatever is typed. |
