A menu of copy items on the [ActionMenu](../action-menu/) machine. Choosing one copies its text and
asks the page toaster for **Copied — &lt;meaning&gt;** (2 s; a new copy replaces the one showing). Two
shapes:

- **Button.** A trigger opens the menu; each item carries its own `text`.
- **Context** (`context`). The default slot holds the *hosts*: any element with a `data-copy`
  attribute, a JSON object of `{ "<item value>": "<text>" }`. Right-click, the menu key,
  <kbd>Shift</kbd> + <kbd>F10</kbd> or a long-press on a host opens the menu at the pointer with the
  items that host has a text for. One menu serves a tag list, a card grid or a table; the data stays
  on each host, so a menu that opens before its script has loaded still copies that host's text.

A host keeps its own tab stop (give it `tabindex="0"` or make it a link or button); the menu adds none,
and focus returns to the host when the menu closes. On empty space, and on an element without
`data-copy`, the browser's own menu shows.

## Host data

| Attribute | Value | Meaning |
| --- | --- | --- |
| `data-copy` | JSON object | `{ "<item value>": "<text to copy>" }`. A host shows only the items it has a text for. Absent, malformed, or without a string text: the element is not a host. |

## Events

| Event | Detail | When |
| --- | --- | --- |
| `ocx:menu:select` | `{ value }` | An item is chosen, before the copy. |
| `ocx:menu:change` | `{ open }` | The menu opens or closes. |
| `ocx:toast` | `{ title, duration, slot }` | After the copy: "Copied — &lt;meaning&gt;", or "Copy failed" (danger) when the browser has no clipboard or refuses the write. |

## Keyboard

| Key | Action |
|---|---|
| Menu key, <kbd>Shift</kbd> + <kbd>F10</kbd> | On a host: open the menu under it. |
| ArrowDown, ArrowUp | Next or previous item. |
| Home, End | First or last item. |
| A letter | Highlight the next item starting with it. |
| Enter, Space | Copy the highlighted item and close. |
| Escape | Close; focus returns to the host (or the trigger). |
