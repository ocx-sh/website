A real table for short pairs: a platform and its digest, a setting and its value.
Header rows and the footer span both columns. One row may be highlighted (the row that is "you"), and a row may end in a note.
A key and a value with its note each stay on one line. Only on a narrow screen do they wrap, the note as one unit, so the table never scrolls sideways.
