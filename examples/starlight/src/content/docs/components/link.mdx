A native `<a>` in the look of a prose link: accent ink and a quiet underline that inks on hover.
Use it where a link sits outside prose, or needs the neutral tone, an external marker or a new tab.
Inside Markdown prose a plain `[text](url)` already looks like this. Hover a link and tab to it to
see the hover and the square focus ring. Switch the theme in the header to check dark mode.

An absolute `http(s)` link to another origin than the site gets the external icon by itself; without
a configured site every absolute link does. `newTab` is never implied: it sets `target="_blank"`,
`rel="noopener noreferrer"` and a visually hidden "(opens in a new tab)" for screen readers. A
disabled link drops its `href`, so it takes no focus and cannot navigate, and keeps `role="link"`.

## Keyboard

- <kbd>Tab</kbd> moves focus to the link; the ring is square.
- <kbd>Enter</kbd> follows the link (a native `<a href>`).
- A disabled link is not in the tab order.
