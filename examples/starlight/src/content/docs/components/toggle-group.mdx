## Events

| Event                     | Detail                                   | When                              |
| ------------------------- | ---------------------------------------- | --------------------------------- |
| `ocx:toggle-group:change` | `{ value }`, the pressed values in order | An option is pressed or released. |

## Setting the value from code

Dispatch `ocx:toggle-group:set` on the group root (`[data-zag-root="toggle-group"]`) to set the
pressed option(s) from a URL or stored state. The detail is `{ value }`, a string or an array of
strings; a value no item carries leaves every item off. It works before the machine has started (the
group then boots from the value) and after, and it never fires `ocx:toggle-group:change`. Do not write
`aria-checked`, `aria-pressed`, `data-state` or `data-zag-props` yourself.

```js
group.dispatchEvent(new CustomEvent('ocx:toggle-group:set', { detail: { value: 'linux' }, bubbles: true }));
```

## Keyboard

The group is one Tab stop; focus enters on the first option.

- <kbd>←</kbd> <kbd>→</kbd> move focus between options, wrapping at the ends.
- <kbd>Home</kbd> <kbd>End</kbd> move focus to the first or last option.
- <kbd>Space</kbd> <kbd>Enter</kbd> press the focused option.
