A skeleton is decorative, so pair it with a [Loader](../loader/) for the announcement. One
component covers the primitives (`text`, `circle`, `rect`) and the composites (`card`, `list`,
`table`, `code`, `terminal`), which reserve the same block size as the component they stand in
for. A faint sweep crosses every bar; it stays still under `prefers-reduced-motion: reduce`,
and `animated={false}` turns it off.

A `code` skeleton takes the block's source as `code`: it draws one bar per line, so a skeleton built
from the same string as its fence is the same height, to the pixel. Add `title` when the fence has
one (Expressive Code's 36px title bar). An untitled `sh` fence has no header in this theme, so it is a
plain `code` skeleton.

## Swapping in the content

Put the skeleton and the content in one `ocx-swap` wrapper. Both share one grid cell, so the box is
the larger of the two and, sized from the same build, nothing moves. When the content is ready, set
`data-loaded` on the wrapper (one attribute, no helper): the content fades in and the skeleton out
over `--ocx-duration-base` (opacity only), and the skeleton ends `visibility: hidden`. With reduced
motion the swap is instant. The [DependencyExplorer](../dependency-explorer/)'s summary stats use it.

```astro
<span class="ocx-swap">
  <Skeleton lines={1} />
  <span id="total"></span>
</span>
<script>
  document.querySelector('#total').textContent = '42';
  document.querySelector('.ocx-swap').dataset.loaded = '';
</script>
```
