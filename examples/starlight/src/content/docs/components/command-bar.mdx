A command you copy by clicking it. The picker swaps the command and shows only its icon (the name and
the tooltip carry the choice, the popup lists icon and label); a picker whose choices lack an icon shows the
label instead of an empty box, and `pickerText` adds the label to an icon. The slot `action` adds a control
at the right edge, ideally an icon-only button: a `Button` with `iconOnly`, an `aria-label` and a `Hint`.
Copying is the [copy button](../copy-button/)'s, the picker a compact [select](../select/).

## Events

| Event | Detail | When |
| --- | --- | --- |
| `ocx:select:change` | `{ value }` | A choice is picked. |
| `ocx:clipboard:copy` | `{ value }` | The command is on the clipboard. |
| `ocx:clipboard:error` | `{ value }` | The browser refused the write. |
| `ocx:toast` | `{ title, duration, slot }` | After a copy: "Copied — Linux install command". |

## Keyboard

- <kbd>Enter</kbd> or <kbd>Space</kbd> on the field: copy.
- The picker takes the [select](../select/#keyboard)'s keys.
