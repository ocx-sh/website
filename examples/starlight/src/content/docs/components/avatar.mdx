A person or entity tile: the initials paint first and the image paints over them once it has
loaded, so a slow network or a broken URL never flashes a half-loaded picture, and no script runs
before first paint. `AvatarGroup` stacks several into one overlapping row, collapsing the rest into
a `+N` tile past `max`.

## Stories

<Stories of="avatar" />

## Events

- `ocx:avatar:status` `{ status: 'error' | 'loaded' }`: the image finished loading or failed; a failed image is hidden, leaving the initials.

## Keyboard

The avatar is `role="img"`, never focusable; no APG widget pattern applies.
