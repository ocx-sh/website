A table of contents that marks the heading you are reading (or the entry you clicked), for pages
that do not have Starlight's own. Its links work before JavaScript; the machine starts when the list scrolls into view, with
no input. Scroll the first story: it lists its own sections. No event log there: the Toc starts at
load, so its script counts before input and the page stays within its script budget.

## Events

| Event | Detail | When |
| --- | --- | --- |
| `ocx:toc:change` | `{ value: string[] }` | The active heading changes: `value` holds its id, or nothing when no heading is active. |

## Keyboard

Plain links in a `nav` landmark; no APG widget pattern applies.

- <kbd>Tab</kbd>: Next entry.
- <kbd>Enter</kbd>: Jump to that heading.
