Use filter chips to narrow a list by one choice (`single`) or several (`multiple`), and plain
chips to show the labels an entry carries (`none`), optionally removable. The chips wrap onto new
lines; the group keeps one Tab stop and the arrow keys walk them in reading order. To type new
values into a field, use a tags input instead.

A selected chip is "current": accent ink on an accent tint with a coral edge and a check. Hover
is neutral, and a disabled chip is flat and subtle. Tab to a group to see the focus ring.

## Events

| Event                  | Detail                                    | When                                                                                                           |
| ---------------------- | ----------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `ocx:tag-group:change` | `{ value }`, the selected values in order | A chip is selected or released (single, multiple).                                                             |
| `ocx:tag-group:remove` | `{ value }`                               | A remove button is used. Cancelable: `preventDefault()` keeps the chip, for example while the server confirms. |

Both bubble. After a removal, focus moves to the next remove button, else the previous one, else
the group.

## Keyboard

Single and multiple: the group is one Tab stop; focus enters on the first chip.

- <kbd>←</kbd> <kbd>→</kbd> move focus through the chips in reading order, across wrapped lines, wrapping at the ends.
- <kbd>Home</kbd> <kbd>End</kbd> move focus to the first or last chip.
- <kbd>Space</kbd> <kbd>Enter</kbd> select or release the focused chip.

Removable:

- <kbd>Tab</kbd> moves between the remove buttons.
- <kbd>Enter</kbd> <kbd>Space</kbd> <kbd>Backspace</kbd> <kbd>Delete</kbd> remove the focused chip.
