Click copy: the value goes to the clipboard, the button reads "copied" for 1.5 s, and a toast
confirms it bottom-right for 2.5 s. Every copy control in the theme toasts, including the copy
button of a code block. The toaster loads on the first toast; three toasts stack at most.

## Events

| Event | Detail | When |
| --- | --- | --- |
| `ocx:clipboard:copy` | `{ value }` | The value is on the clipboard. |
| `ocx:clipboard:error` | `{ value }` | The browser refused the write. |
| `ocx:toast` | `{ title, tone? }` | After either: "Copied …", or "Copy failed" with `tone: "danger"`. Any script may dispatch it. |

## Keyboard

- <kbd>Enter</kbd> or <kbd>Space</kbd> on the button: copy (a native button).
- <kbd>Alt</kbd> + <kbd>T</kbd>: move focus to the toasts; <kbd>Tab</kbd> reaches each one.
- <kbd>Escape</kbd> on a focused toast: dismiss it.
