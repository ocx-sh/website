Click copy: the value goes to the clipboard, the button reads "copied" for 1.5 s, and a toast
confirms it bottom-right for 2 s: **Copied — &lt;label&gt;**. A second copy while it reads "copied" starts
the 1.5 s over. Every copy control in the theme toasts the same way and replaces the toast
showing, including [CopyMenu](../copy-menu/), [ProseCodeCopy](../prose-code-copy/) and the copy button of
a code block. Where the browser has no clipboard (an insecure context) or refuses the write, nothing
throws: the toast reads "Copy failed" and the button stays as it was. The toaster loads on the first
toast; three toasts stack at most.

## Events

| Event | Detail | When |
| --- | --- | --- |
| `ocx:clipboard:copy` | `{ value }` | The value is on the clipboard. |
| `ocx:clipboard:error` | `{ value }` | The browser refused the write. |
| `ocx:toast` | `{ title, duration?, tone?, slot }` | After either: "Copied — …" (2000 ms), or "Copy failed" with `tone: "danger"`; both in the `copy` slot. Any script may dispatch it. |

## Keyboard

- <kbd>Enter</kbd> or <kbd>Space</kbd> on the button: copy (a native button).
- <kbd>Alt</kbd> + <kbd>T</kbd>: move focus to the toasts; <kbd>Tab</kbd> reaches each one.
- <kbd>Escape</kbd> on a focused toast: dismiss it.
