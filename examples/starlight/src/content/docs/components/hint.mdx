A hint names what an icon button does. The button keeps its own `aria-label`; the hint is its
description while shown. For definitions of terms in prose, use [Tooltip](../tooltip/).

The default slot is the one `<button>` or `<a>` the hint describes.

## Events

- `ocx:hint:change` `{ open }`: the hint shows or hides.

## Keyboard

| Key | Action |
|---|---|
| Tab | Focusing the button shows the hint. |
| Escape | Hide the hint. |
