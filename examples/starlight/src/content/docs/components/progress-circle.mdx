A ring with `role="progressbar"`, named by `label`. Without a `value` it is indeterminate: a quarter
arc that spins, and stands still under reduced motion. It ships no JavaScript. To move a determinate
ring, set `aria-valuenow` and `style="--_value:N"` (unitless, 0 to 100) on the root.

`Loader` stays the calm square; the ring is for progress that a toast or a task reports.
