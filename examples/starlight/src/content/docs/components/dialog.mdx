A modal dialog. While it is open, focus stays inside, the page does not scroll, and the rest of
the page is hidden from assistive tech. Escape, an outside click or the close button closes it
and returns focus to the trigger. `ConfirmDialog` and `AlertDialog` build on it:
[Dialog presets](../dialog-presets/).

Slots: `icon` (next to the title, e.g. a tone icon), `trigger` (the trigger button's content; no
trigger, and the dialog opens only via `ocx:dialog:open`, when absent) and the default slot (the body).

## Events

- `ocx:dialog:change` `{ open }`: the dialog opens or closes.
- `ocx:dialog:open` `{ id }`: dispatch on `document` to open the Dialog whose id matches.
- `ocx:dialog-result` `{ id, value }`: the [presets](../dialog-presets/) emit this exactly once per close (`'dismiss'` for Esc, X or outside click).

## Keyboard

| Key | Action |
|---|---|
| Enter, Space | On the trigger: open the dialog; focus moves into it. |
| Tab, Shift+Tab | Move focus within the dialog; it wraps at the ends. |
| Escape | Close the dialog; focus returns to the trigger. |
