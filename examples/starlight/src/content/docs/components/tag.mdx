A label is a tint fill for a passive category. A stamp is outline caps for a status fact: stamp
only the exception, stable things get none. Switch the theme in the header to check dark mode.
For Starlight's own inline stamp — a heading or sidebar `badge:` — see [Badge](../badges/)
instead; Tag is for page content.

The filter chip is the one that responds: coral ink, tint and edge with a trailing check when on
(`aria-pressed`, `aria-checked` or `data-state="on"`), surface and hairline when off. A removable
chip ends in a square remove button. Tag itself holds no behaviour; TagGroup and TagsInput drive
pressing and removing.
