Tiles for a short list of named things: registries, platforms, hosts.
The tiles sit in two columns, one on a very narrow screen, with a hairline between them.
The `footer` slot spans both columns under the tiles: a command bar or a command.
An icon comes from the theme's icon set by name. An unknown name fails the build.
