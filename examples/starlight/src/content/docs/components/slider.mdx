A track with one thumb, or two when `value` is a pair. The value text sits beside the label and
hidden inputs carry the values into a form, so it submits before any script loads. The machine
loads on first hover or focus; a press before that is lost, since a drag cannot be replayed. To
display a number only, use [Meter](../meter/).

## Events

| Event               | Detail                                         | When                                                         |
| ------------------- | ---------------------------------------------- | ------------------------------------------------------------ |
| `ocx:slider:input`  | `{ value }`, a number, or an array for a range | The value changes, on every step of a drag.                  |
| `ocx:slider:change` | `{ value }`, same shape                        | A change ends: the pointer is released, or a key is pressed. |

## Keyboard

Each thumb is a Tab stop. A range's thumbs cannot cross.

- <kbd>→</kbd> <kbd>↑</kbd> raise the focused thumb by one step.
- <kbd>←</kbd> <kbd>↓</kbd> lower it by one step.
- <kbd>PageUp</kbd> <kbd>PageDown</kbd> move it by the large step (ten steps).
- <kbd>Home</kbd> <kbd>End</kbd> jump to the lowest or highest allowed value.
