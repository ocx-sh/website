A text input with a filtered list, on the Zag combobox (loaded on first hover or focus). Filtering
is fuzzy by default: a subsequence match ("cfo" finds "CMake · find_ocx") ranked best-first and
tolerant of a single typo, with the match(es) marked in each option. Pass `matchMode="contains"` or
`matchMode="startsWith"` for a plain substring filter instead. The `start` and `end` slots put a
control inside the box, such as a sort-direction toggle.

## Events

- `ocx:combobox:input` `{ query }`: The input text changes.
- `ocx:combobox:change` `{ value }`: An option is committed.

## Keyboard

- Typing: Filters the options and opens the list.
- <kbd>↓</kbd> <kbd>↑</kbd>: Opens the list, moves the highlight.
- <kbd>Enter</kbd>: Commits the highlighted option and closes.
- <kbd>Esc</kbd>: Closes the list; pressed again, restores the input to the committed option.
- <kbd>Tab</kbd>: A control in the `start` or `end` slot is its own tab stop.
