A panel of free content next to its trigger. Escape or a click outside closes it and returns
focus to the trigger. The trigger names the panel.

Slots: `trigger` (the trigger button's content) and the default slot (the panel).

## Fetch on open

`src` fills the panel from a URL, for content the page cannot afford to ship up front (a version preview, a
long list). Nothing is fetched before the first open: the machine itself loads on the first hover or focus,
and the fetch starts when the panel opens. The panel shows the Loader, then the fragment, or the error text with
a Retry button that fetches again. The result is cached by URL for the page's life, so reopening, or a
second popover with the same `src`, makes no request. The panel floats over the page, so a growing panel never
moves the content around it. The region is a polite live region with `aria-busy` while loading.

The fragment must be same-origin HTML your own build produced: it is inserted as markup, and any other
origin counts as an error. For plain text beside an icon button, use [Hint](../hint/)'s `src`.

## Events

- `ocx:popover:change` `{ open }`: the panel opens or closes.
- `ocx:popover:fill` `{ ok }`: a `src` fetch finished; `ok` is false on an error. Listen to enhance the fragment.

## Keyboard

| Key | Action |
|---|---|
| Enter, Space | On the trigger: toggle the panel. |
| Tab | Move through the panel's content; leaving it closes a non-modal panel. |
| Escape | Close the panel; focus returns to the trigger. |
