A native `<input>` drawn as a checkbox, a radio or a switch. The input is the form control: it
toggles and submits before any script runs. Checkbox and switch load the Zag machine on first
hover or focus and report changes; a click that came earlier is kept. `type="radio"` stays a plain
native radio with no machine; for a set of radios, use [RadioGroup](../radio-group/).

## Events

- `ocx:checkbox:change` `{ checked }`: A checkbox toggles.
- `ocx:switch:change` `{ checked }`: A switch toggles.

## Keyboard

- <kbd>Tab</kbd>: Moves focus to the choice.
- <kbd>Space</kbd>: Toggles the checkbox or switch.
