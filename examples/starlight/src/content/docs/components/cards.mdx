import { Card, CardGrid, LinkCard } from '@astrojs/starlight/components';

Every card is the same box: a hairline border, a 2px corner, the card padding and no shadow. An
icon sits in a square neutral tile beside the title. A card that is a link lifts its border to
the neutral hover border on hover and shows the focus ring on keyboard focus; it never turns
coral, which is kept for links, the current item, primary actions and focus. A card that is not a
link has no hover. Hover the link cards below, and switch the theme in the header for dark mode.

## Theme card

`.ocx-card` (base.css) is the same card for pages outside Starlight's components, such as
hub and landing pages. As an `<a>` it takes the hover border and focus ring; `--planned`
marks an entry that does not exist yet.

<CardGrid>
  <a class="ocx-card" href="../">
    <strong>link card</strong>
    <span>An anchor with the class: hover lifts the border.</span>
  </a>
  <div class="ocx-card">
    <strong>static card</strong>
    <span>A div with the class: no hover.</span>
  </div>
  <div class="ocx-card ocx-card--planned">
    <strong>planned card</strong>
    <span>Dashed and transparent: not there yet.</span>
  </div>
</CardGrid>
