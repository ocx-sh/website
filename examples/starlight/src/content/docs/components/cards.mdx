title: Cards

import { Card, CardGrid, LinkCard } from '@astrojs/starlight/components';

Every card is one box: hairline border, 2px corner, card padding, no shadow. A link card lifts
its border to the neutral hover border and shows the focus ring; it never turns coral. A card
that is not a link has no hover.

## Card

With an icon:

<Card title="docs" icon="open-book">
  Guides and reference for the ocx CLI.
</Card>

Without an icon:

<Card title="catalog">Browse packages in the index.</Card>

## CardGrid

Cards in a row are equal height, whatever their body length.

<CardGrid>
  <Card title="docs" icon="open-book">
    Guides and reference for the ocx CLI.
  </Card>
  <Card title="catalog" icon="rocket">
    Browse packages in the index. This body runs longer, and the card beside it grows to the same height.
  </Card>
</CardGrid>

## Theme card

`.ocx-card` (base.css) is the same card for pages outside Starlight's components, such as
hub and landing pages. As an `<a>` it takes the hover border and focus ring; `--planned`
marks an entry that does not exist yet.

<CardGrid>
  <a class="ocx-card" href="../">
    <strong>link card</strong>
    <span>An anchor with the class: hover lifts the border.</span>
  </a>
  <div class="ocx-card">
    <strong>static card</strong>
    <span>A div with the class: no hover.</span>
  </div>
  <div class="ocx-card ocx-card--planned">
    <strong>planned card</strong>
    <span>Dashed and transparent: not there yet.</span>
  </div>
</CardGrid>

The [dependency explorer](../dependency-explorer/)'s summary facts are this card too.
