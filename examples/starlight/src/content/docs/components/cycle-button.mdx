---
title: Cycle button
description: A button that steps through two or more states, each click swapping its icon for the next state's.
---

import PropsTable from '../../../components/showcase/PropsTable.astro';
import Stories from '../../../components/showcase/Stories.astro';

Use it when one control owns a choice of a few states and the state itself is the label, such as the
theme switch or a sort direction. It is a native `<button>` that shows only the current state's icon;
a click shows the next one and wraps after the last. For an on/off choice use a
[toggle button](../toggle-button/); to pick among options shown side by side, a
[toggle group](../toggle-group/). The state is in the page before any script runs.

## Events

| Event                     | Detail                | When                                                                                                 |
| ------------------------- | --------------------- | ---------------------------------------------------------------------------------------------------- |
| `ocx:cycle-button:change` | `{ value, previous }` | A click is about to show the next state. It bubbles and is cancelable: prevent it to keep the state. |

## Keyboard

- <kbd>Tab</kbd> moves focus to the button.
- <kbd>Space</kbd> <kbd>Enter</kbd> show the next state.
